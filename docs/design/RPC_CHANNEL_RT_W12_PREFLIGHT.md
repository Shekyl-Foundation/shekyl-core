# RT-W12 client transport pre-flight

**Status: OPEN** — RT-W12 step 1. Authorized 2026-11-21. Implementation in progress, starting with the regtest harness. The wallet grammar and RT-W12 steps 1–3 ship together in alpha.13. See the [channel design](RPC_CHANNEL.md) and the [wallet grammar PR](https://github.com/Shekyl-Foundation/shekyl-core/pull/1553).

## What landed

Grounded on core `dev` at `d09a38070c` on 2026-11-25. The review compared the brief's baseline `d2472aa13` and its wallet-listener baseline `59f56fda42` to this tree. The intervening development includes 53 numbered PR merges. The table follows the affected callers at the landed SHA. The wallet grammar is on a separate branch.

The changes since the brief fall into four groups relevant to integration:

- **Wallet and RPC.** Wallet preferences were removed (#1501), the builder now checks membership before a spend leaves the wallet, send has an input-cap refusal (#1527), and the group wallet gained its on-disk representation (#1510). The RPC cutover must carry these existing refusals without turning them into transport failures. The version in the brief predates the current error contract.
- **Process startup and local transport.** Shared stop handling (#1490), tunnel packaging (#1508), CLI socket cleanup (#1509), owner-only permissions before a socket listens (#1533), and side-effect-free startup refusals (#1541) landed. Apply D13 during the same configuration checks used by startup and verification. Preserve the private socket's creation and cleanup path.
- **Regtest.** Relay and embargo fixes (#1485, #1516, #1520), a five-node emission walk (#1522), and the progress-driven scan wait (#1546) changed the harness. Move each spawned daemon's clients to its own rendezvous. Some tests deliberately observe TCP or run an older peer.
- **Build and other lanes.** Crypto timing and correctness, chain-forge corpora and fees, economics simulations, emission accounting, fuzz coverage and CI policy also advanced. #1544 moved the build entry point to Cargo xtask. These merges were inventoried for integration impact. This review traces the wallet, RPC and test paths below and makes no verification claim about unrelated consensus or cryptographic implementations.
