- **The RandomX verifier no longer leaves the floating-point rounding mode set.** Each RandomX floating-point instruction now runs in its own block: it writes a fixed control word (IEEE defaults plus the mode CFROUND chose, with flush-to-zero off), computes, and writes back the caller's word. Before this, the mode stayed in the hardware while ordinary Rust code ran under it. On x86 a hash also left flush-to-zero and denormals-are-zero on, and a panic mid-hash left a directed mode set on both architectures. Hashes are unchanged. Hash time on the floor device is about 9 % higher. The design and its measurements are `docs/design/RANDOMX_ROUNDING_DECISION.md`.
