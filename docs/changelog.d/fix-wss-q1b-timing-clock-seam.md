- **The Q1b bench's timing tests no longer depend on the machine being quiet** (`shekyl-wss-q1b-bench`). The convergence loop reads time through a clock: the shipped entry points read the monotonic clock as before, and the tests drive a clock the workload advances by exact amounts. Real sleeps had let scheduler lag on a loaded machine close the gap between the two convergence windows, so a workload slowing 6 % per sample read as converged. One test still runs the real clock, asserting only what load cannot change.
