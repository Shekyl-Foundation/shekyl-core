- **Process: a pull request's CHANGELOG entry is a file of its own until the release cut** (`docs/changelog.d/README.md`). Every pull request inserted its line at the top of `[Unreleased]`, so any two open ones conflicted, and each merge sent the others back for a merge of `dev` and a full CI run. An entry is now a new file under `docs/changelog.d/`, named after its branch; the release cut (`RELEASING.md` step 1) moves the entries into `docs/CHANGELOG.md` and deletes the files. The doc-claims, FOLLOWUPS-target and multisig-literal gates treat an entry there as they treat one in `docs/CHANGELOG.md`.
