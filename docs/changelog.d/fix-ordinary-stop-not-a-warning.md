- **Daemon: a stop the operator asked for is announced, not a warning** (`INPUT_GRAMMAR.md` IG-14; alpha.11 bug hunt; Rick, 2026-11-06). Every service stop on the alpha.11 fleet logged `WARN … stop requested by SIGTERM`, which reads as a fault. A stop asked for by a signal, a Windows console event or the RPC's `stop_daemon` is now an IG-14 announcement: `stop requested by <cause>` on standard error and in the log whatever the log level, with no level tag, as the start's announcements are. A forced stop (chain sync's owner ending on its own) is an `error` line, `stop forced: <cause>`. The cause is a type (`StopCause`), not a string, so the stop line can no longer read "a stop" when the cause was lost.
