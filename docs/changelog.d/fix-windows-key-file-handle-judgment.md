- **Windows: a key file is judged by the handle that reads it, and cannot be swapped while it is held** (`TOR_SUPERVISOR.md` `TSR-Q15`). `tor-onion-key-file` used to judge the path's owner-only label and then read through a handle opened separately, so a rename of the name between the two could hand the daemon a different file. The file is now opened sharing reading only, so no other open can rename, replace or write it until the read is done. A reparse point at the name, such as a symbolic link, is refused, and so is a directory. The handle's own descriptor is judged in one read: owned by this account, an access list that admits no other account, and a no-read-up label, together. A backup agent or scanner that only reads the file does not stop the start; a process holding it open for writing does, and the start says so.
