- **The FCMP++ prover is correct in every build, not only in debug builds.** The vendored `generalized-bulletproofs`, `circuit-abstraction` and `fcmps` (Foundation fork PR #9) checked their vector lengths, the prover's witness and the circuit's role only with debug assertions, so a release build could compute over a truncated vector or prove a witness that does not satisfy its statement, producing a proof no verifier accepts. Every length is now checked in every build; the prover can only prove commitments it made from its own openings, and forming it checks every constraint; a circuit is built for one role, proving or verifying, so a multiplication's witness can be neither missing nor misplaced. Proof bytes do not change: a new pinned vector (`a_seeded_proof_is_pinned_byte_for_byte`) holds them across the change.
