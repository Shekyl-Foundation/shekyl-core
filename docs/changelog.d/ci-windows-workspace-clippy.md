- **Process: the Windows build runs the Linux gate's clippy lanes** (`.github/workflows/build.yml`, job `build-windows-msvc`). The Linux gate never compiles a `cfg(windows)` arm, so Windows-only code went unlinted, and gungraun's `client_requests` feature, unified into every crate, kept the workspace's test targets from building with MSVC at all. The feature is now Unix-only; the lint findings in Windows and non-Unix arms, across ten crates, are fixed; the Windows job runs each lane to the end and fails on the first that does not pass.
