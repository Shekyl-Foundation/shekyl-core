- **The managed Tor's clock line is said once, in one sentence** (`TOR_SUPERVISOR.md` §4.4, §5 "Clock skew"). With this computer's clock three days behind, the node said the clock 11 times in 3.5 minutes on Windows and 18 times in 4 minutes on macOS, each line carrying "The clock is off by -259201 seconds. Check time sync." beside a second clock sentence. The line now says the clock once while it stands, and once more when it is set right: "This computer's clock is 3 d 0 h behind the Tor network's. Others may not be able to reach this node. Check this computer's date and time." The figure is Tor's when Tor gave one, and the node's own lower bound otherwise. A clock ahead is said "ahead of". While Tor is starting, a bootstrap problem or an unreachable directory no longer replaces the clock with "cannot reach the Tor network". A fixed consensus aging into the tolerance drops this node's lower bound and does not retire Tor's own report, so the same fault is not said again when Tor repeats it. The report is retired when the gap closes faster than the time that passed.
