- **The mempool tests and the Tor transit spike own their temp directories.** `shekyl-mempool`'s pool tests opened their files at a hand-built path under the system temp directory and removed only the `.redb`, so every run left the store's `.creation-lock` behind; they now take a `TestPath` (a `tempfile` directory holding the pool file), as the chain-store, chain-ingest and p2p-harness tests do, removed when the test ends, a panicking test included. The transit spike's tor data directories are a `tempfile` directory too: removed when the session ends however it ends, and kept, as before, when the session fails.
