- **`shekyld --config-file none` runs on the command line and the defaults alone; `clearnet-listen none` beside `clearnet off` is accepted** (Rick, 2026-11-18). `none` reads no configuration file, whatever is at the default path, and the startup line says `config-file=none (cli)`; a program that starts its own daemon (the GUI wallet) passes it, so its node means the same on every machine whatever a service install keeps in `/etc/shekyl/shekyld-<network>.toml`. The path kind takes keywords as the integer and quantity kinds do (`Kind::PATH`, `Kind::PATH_OR_NONE`), and the loader's file step is typed (`ConfigFileChoice`: named, default, none). Under a connector that is off, a list child given as `none` asks for nothing and is no longer `config.value.conflict`: `clearnet off` with `clearnet-listen none` is one statement, twice. An endpoint under an off connector is still refused.
