- **Chain L, the lifecycle test chain** (`CHAIN_FORGE.md` §3, §4, `CF-4b`): one forged regtest chain on the settled schedule that carries every event the catalogue can place on a chain today, from the first spends, the filled blocks and five reorgs through two shard closes, a compact and a complete-tree join, a settled epoch, an emission claim, a slash, a reinstate, a release and the collect. Each event the plan names is checked against what it promises as it is forged. Every transaction pays the standard fee rung and passes the daemon's pool. A reorg the store refuses now stops the forging.
- **The snapshot cache** (`CHAIN_FORGE.md` §8): a test or bench can start from the store a full production replay left at one of Chain L's events instead of rebuilding the chain. A snapshot is built only by that replay, keyed on the pinned chain, the store's schema and the consensus code, and refused on open if one byte moved. Every snapshot a consumer opens is rebuilt from genesis each night and held to the pinned trace. The emission claim's scenario test now starts from one, and the emission claim's block has a nightly instruction-count row of its own.
