- **Each packaged settings file shows its own network's ports.** The testnet and stagenet files in the `.deb` and `.rpm` (`/usr/share/shekyl/shekyld-<network>.toml`, copied to `/etc/shekyl/`) showed mainnet's ports in their commented examples. The listen examples now show the default a start on that network binds (`clearnet-listen` `0.0.0.0` and the P2P port, `rpc-admin-listen` `127.0.0.1` and the RPC port), and the peer and advertised examples show that network's P2P port. The operator's own SOCKS proxy and Tor forward (`tor-socks`, `clearnet-socks`, `tor-onion-listen`) have no default port, so their examples are now placeholders, where they had named the RPC port. Only the comments change: a file installed by an earlier package stays as it is, and nothing it sets is read differently.
