- **The wallet binaries read the input grammar's option tables** (`INPUT_GRAMMAR.md` §12). `shekyl-cli` and `shekyl-wallet-rpc` take their options and a configuration file through the table the daemon's options use, with generated help and one spelling per option. **Breaking for scripts:** `--daemon-address` is `--daemon-endpoint` (an IP or an onion and a port, no URL or hostname), `--proxy` is `--daemon-socks` (an IP and a port, SOCKS5, no login), `--rpc-url` is `--wallet-rpc-endpoint` or `--wallet-rpc-socket-file`, `--wallet` is `--wallet-file` (the absolute path of `<name>.wallet`), `--password-file` and `--password-stdin` are `--wallet-password-file`, `--script` is `--script-file`, `--complete-tree-foundation` and `--acknowledge` are `--archival-complete-tree` and `--archival-acknowledge`, `--testnet` and `--stagenet` are `--network`, and on the server `--rpc-bind` is `--rpc-listen` or `--rpc-socket-file`. `--rpc-login` moves to `rpc-username` and `rpc-password` in the configuration file, and `--disable-rpc-login` is gone. CLI options now come before the command.
- **`wallet create` and `wallet restore` replace the `create` and `restore` subcommands.** `--mnemonic-file` writes the recovery words to a new owner-only file or reads them from one, and `--wallet-restore-height` names the block to scan from. The words no longer travel on a command line: without a file, `wallet restore` asks for them without echo. A password or recovery-words file another account can read is refused.
- **Logging is set by options, and a wallet writes no log file unless you name one.** Both wallet binaries take `log-level`, `log-category`, `log-file` and `log-size-max`, and `log-category` gains `wallet`. The `SHEKYL_LOG` and `RUST_LOG` variables are no longer read. `shekyl-wallet-rpc`'s default level is now `warn`.
- **A wallet checks its address derivation before it uses it.** `wallet create`, `wallet restore` and every open run the derivation self-check first and refuse with `-29018 DERIVATION_SELF_CHECK_FAILED`, naming the build's platform. The check takes about 0.6 ms on a Raspberry Pi 4. The `derivation-freeze-self-check` command is removed. Wallet RPC contract 0.25.0; api_version stays 1.
- **`config-verify` on both wallet binaries.** It checks the configuration as a start would and prints the effective configuration. `shekyl-wallet-rpc` also prints that line at every start.
