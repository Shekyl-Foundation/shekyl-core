- **A wallet open refused by the random-number check has its own code.** With `conformance`, `shekyl-engine-core` checks this computer's random-number source before the wallet stakes, and refuses the open when the source fails (S6). `OpenError::StakeRngSelfCertFailed` used to exist only in that build, so turning the feature on changed the shape of a public enum and `shekyl-wallet-contract`'s exhaustive mapping stopped compiling. The variant is now a unit in every build, so every match names it and the default build still carries no float grader. The grade is logged where the check runs. The contract maps the variant to `-29017 RANDOM_SOURCE_CHECK_FAILED`: try once more (the check's false alarms are about one in a million), and on a second failure open the wallet on another computer. Wallet RPC contract 0.21.0; api_version stays 1.
