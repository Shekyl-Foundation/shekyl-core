- **A wallet call no longer hangs on a daemon that has just stopped.** When a daemon stopped, a client's next call on the closed connection could wait for an answer that would never come, for up to the session's one-hour idle limit. The call now fails at once with the connection-closed error, and an answer that had already arrived is still delivered.
- **The `merge-ready` label no longer re-runs tests.** It tells the merger the head is ready. The combination of two pull requests is `dev`'s own run. At label time the head must merge with the newest `dev`, and the fuzz lockfiles must agree with the workspace lock on that merge; that check reads files. A pull request's CI is scoped from the `dev` its merge commit was built on.
