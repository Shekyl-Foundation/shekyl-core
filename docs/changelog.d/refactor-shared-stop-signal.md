- **The wallet RPC server keeps Ctrl-C off when the program that started it asked for that** (`INPUT_GRAMMAR.md` IG-14; Rick, 2026-11-20). A `shekyl-wallet-rpc` started with `SIGINT` ignored (a non-interactive background list, `trap "" INT`) used to take `SIGINT` anyway and stop on it. It now keeps the ignore and says once, at start, that Ctrl-C is off and that `SIGTERM` stops it. `SIGTERM` still closes the open wallet and stops the server cleanly, and a second `SIGTERM` exits at once. This is the rule the daemon already follows.
