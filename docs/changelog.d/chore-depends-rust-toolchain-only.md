- **Release builds fetch their sources from the Foundation's mirror first** (Rick, 2026-11-18/19). Depends now holds only what the Rust release build uses: macOS's SDK, clang, cctools and libtapi, and FreeBSD's base system as the sysroot; the C++-era packages (Boost, OpenSSL, libsodium, readline, ncurses, ICU, gtest and the rest) and their patches are deleted. Each source is fetched from the Foundation's mirror (`MIRROR_DOWNLOAD_PATH`) and then, if the mirror does not hold it, from its own upstream; either way it is kept only if it matches its pinned SHA-256. The inherited fallback to Monero's depends mirror is gone: it did not carry FreeBSD's base system, and on 2026-11-18 two gitian runs failed when download.freebsd.org timed out and that fallback answered 404. `scripts/ci/check_depends_mirror.py`, in the bundled grep gates, runs depends' own fetch against local servers: with upstream blocked the mirror's file is fetched and passes its hash, a mirror file with one byte changed fails, a file the mirror lacks comes from upstream, and a file neither holds fails.
