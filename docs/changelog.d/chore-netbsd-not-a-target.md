- **A platform is supported only if CI or gitian builds it: Linux, macOS, Windows and FreeBSD** (Rick, 2026-11-17). OpenBSD, NetBSD, DragonFly BSD, illumos and Solaris are not supported, and their code paths go: `shekyl-daemon-config`'s account walk names none of them (its BSD `getpwent_r` convention is now FreeBSD's alone), `CMakeLists.txt` loses its `OPENBSD` branches, and `randomx-v2-sys` no longer names OpenBSD's C++ runtime. A build for any of them stops at the account walk's `compile_error!`. `docs/INSTALLATION_GUIDE.md` §2 states the rule, the README's sections for those platforms say they are unsupported in place of build steps, and the FOLLOWUPS row that asked whether NetBSD stays a target is closed.
