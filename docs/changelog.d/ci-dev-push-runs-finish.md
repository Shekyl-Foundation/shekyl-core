- **CI: a run on `dev` that has started finishes.** In the build, Rust, fuzz-harness and benchmark workflows, only a pull request's newer push cancels its older run. A merge to `dev` queues behind the running `dev` run, and a newer merge replaces the queued one. From 2026-11-10 to 11-17, merges cancelled 50 of 84 Rust runs and 41 of 85 build runs on `dev`, 2,618 runner-minutes that reported nothing, and the Rust suite often had no verdict on `dev` for hours. Run on that week's merges, the new setting costs about 700 to 2,000 more runner-minutes a week, and every started `dev` run reports. `scripts/ci/check_dev_push_runs_finish.py` (in `grep-gates.yml`) holds the four workflows to the one form; rule 06 says what a burst of merges now runs.
