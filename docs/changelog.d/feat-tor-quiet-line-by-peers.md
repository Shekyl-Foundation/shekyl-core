- **The posture line says whether this node knows any peer when nothing comes through Tor** (`TOR_SUPERVISOR.md` §4.2, `DIALER_OUTAGE_EVIDENCE.md` §6). It said "Nothing has come through Tor for N: no connection has opened, and no peer has sent anything." whatever the dialer held. It now says "No peers are known yet." when the dialer holds no Tor address, and "Peers are known; none has answered through Tor for N." when it holds some and a Tor dial failed. Neither names a cause, since only Tor's own statements do. Each is said once when it begins, and again only when it changes from one to the other.
