- **The posture line says whether this node knows any peer when nothing comes through Tor** (`TOR_SUPERVISOR.md` §4.2, `DIALER_OUTAGE_EVIDENCE.md` §6). It said "Nothing has come through Tor for N: no connection has opened, and no peer has sent anything." whatever the dialer held. The dialer's census is pending until the first wake, empty when no Tor address is held, or a count with the time that non-empty run began. Every wake that plans publishes it, including one that only resumes a retry. A connector that cannot dial returns before the census. Once `quiet_after` has passed, an empty census says "No peers are known yet." A non-empty run says "Peers are known; none has answered through Tor for N." when a Tor dial launched in that run has failed; N starts when the run did, or at the quiet stretch, whichever is later. A census that has not arrived says nothing. Neither sentence names a cause, since only Tor's own statements do. Each is said once when it begins, and again only when it changes from one to the other.
