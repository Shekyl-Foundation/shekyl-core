- **A replay holds every table of the store to the trace at each indexed event** (`CHAIN_FORGE.md` §8, `CF-4b`). The chain store computes a tables digest: one 32-byte commitment to every table it holds, row for row (`shekyl_chain_store::tables_digest`, domain `shekyl/chain-store/tables-digest/v1`), covering the archival, output and alternative-chain tables the logical-state digest leaves out. The trace carries it at each event a forged chain's plan indexes, keyed by the event's corpus record (trace record `0x05`, `TRACE_VERSION 0x02`, media type `application/vnd.shekyl.trace.v2`). The replay takes the digest right after that record, before the next one is applied, and reports `EventDiverged` when it differs from the trace's and `EventUnreached` when the run never takes it, because the corpus ends first or a refusal ends the run at or before the record. The five vectors' traces, the small chain's manifest and the hosted shard-fill chain's trace are re-baselined; no block or corpus byte moves.
