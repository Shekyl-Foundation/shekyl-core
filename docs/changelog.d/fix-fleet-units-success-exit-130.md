- **The fleet's shekyld units do not restart after an operator's forced stop** (Rick, 2026-11-21). `utils/fleet/skl-node@.service` and `skl-clearnet@.service` restart `shekyld` when it fails, and they took exit 130, the exit of an operator's second stop, for a failure and restarted it. They now carry `SuccessExitStatus=130`, as the packaged unit has since #1490, so exit 130 counts as success. The launch-recipe gate requires 130 among the `SuccessExitStatus` statuses of every unit that restarts `shekyld`. Fleet hosts pick this up when their units are redeployed.
