- **The dialer no longer dials a node that has dialed in** (ruled 2026-11-09). A host with a live session in either direction, or a pending attempt, is not a dial candidate. The filter used to count outbound sessions only, so a node would dial a peer that already held an inbound session to it. That handed any node that connects a free outbound slot, the eclipse attacker's cheapest step, and between two nodes it made a loop: a stem sent on one session came back on the other, and an origin published its own transaction within seconds instead of at its embargo. The nightly slow lane's embargo walk had been failing on exactly this since 11-07 (#1294). The outbound target stays a best effort at that many distinct nodes.
