- **The default wallet directory is named once, per network, beside the wallet files** (Rick, 2026-11-20). `shekyl_engine_file::paths::wallet_dir_in(root, network)` names `wallets/<network>` in the per-account root, the network's name from its row, mainnet included; `shekyl-cli` and the GUI wallet both read it there, so the GUI's wallets move from `wallets/` to `wallets/<network>/` as the CLI's already were. `shekyl-os-account` loses `wallet_dir_in` and `WALLET_DIR_NAME` and stays a leaf with no network table. The CLI now joins the network it parsed, not the flag's text.
- **`shekyl-cli` makes its wallet folder only to make a wallet.** Every command that started a self-hosted wallet session made `wallets/<network>` at the start, so an `rpc` enrollment word, which opens no wallet, left an empty folder (seen on Windows; the code is the same on Unix). The folder is now made right before a create or restore (`RpcSession::make_wallet_dir`), where the wallet server would otherwise refuse a missing one (`-29009 WALLET_DIR_MISSING`); the per-account root is still made at the start.
