- **Benchmarks: RT-P5's message sizes are registered again on the 4.x wire.** The RPC channel's record size classes (`RPC_CHANNEL.md` §4.4, RT-O6) were derived from a trace of the 3.x wire, whose REST paths and method names the 4.0 rename replaced. A new registration (`docs/benchmarks/rt_p5_rpc_message_sizes_20261115.md`) measures the same generated wallet's traffic, under the same instrument, derivation rule, gates and determinism check, with its subjects named as 4.x methods (`tx_submit`, `block_show`, `chain_height`, `fee`) and seeds no earlier run used. It reports whether the trace's three-class table rounds to RT-O6's 512, 16,384 and 65,535, whether every request other than a submission is still at most 512 bytes, and the submission body's encoding, and leaves any change to the classes to the maintainer. The instrument reads the record constants from `shekyl-noise` instead of restating them, and the derivation script's tests check its copies against that crate. The 2026-10-17 record is unchanged. This measurement gates RT-W12.
