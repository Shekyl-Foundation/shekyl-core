- **A fuzz coverage miss names whether the crate still reaches its own code.** A nightly leg under its floor stays green when the crate's own sources are unchanged since the commit that measured the floor and coverage still meets the codegen allowance (the default tolerance minus one spread-limit, `scripts/ci/fuzz_coverage.py`). The verdict names the fuzz-lock packages whose versions moved. A deeper drop, a drop after those sources changed, or a run whose sources could not be read, stays red. The floor itself is still the coverage a measured run reached, and it still moves only with that run.
