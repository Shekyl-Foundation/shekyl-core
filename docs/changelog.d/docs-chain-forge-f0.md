- **Design: the chain forge and the canonical test chains (Round 0).** `docs/design/CHAIN_FORGE.md` (moved from `docs/CANONICAL_CHAINS.md`) designs one tool that forges the chains every lane tests against: Chain L for the archival lifecycle, B for the bundle producer, P for the production schedule under load, and W for live LWMA difficulty. Each regenerates byte for byte at a commit, carries only regtest's network identity, and has its seeded randomness confined to test-only features. The document holds the census of consumers, the event catalogue, the determinism contract and its seed seams, corpus layout 4 with alternative branches, the snapshot cache, and the regeneration and storage policy. The lane's rulings are in the decision log; its identifier family `CF-` is registered in the implementation index. No code changes.
