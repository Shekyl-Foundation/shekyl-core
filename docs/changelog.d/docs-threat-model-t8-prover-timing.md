- **The wallet threat model names T8: timing on the proving machine** (`docs/THREAT_MODEL_WALLET.md`; `CA-2`). On some x86_64 processors the FCMP++ prover's field arithmetic takes time that depends on the values it works on. A process sharing the proving machine's CPU could observe it; it is not observable remotely, and verification works on public data only. Until the fix ships, build transactions on a machine whose CPU you do not share with software you do not trust. A fix is in progress.
