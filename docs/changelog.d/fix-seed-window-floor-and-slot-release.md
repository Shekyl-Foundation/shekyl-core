- **Daemon: a RandomX cache the chain no longer needs is released, not held until the next epoch** (alpha.11 bug hunt A2; Rick, 2026-11-07). The ingest's seed window reached below the chain's lowest poppable height, so for the first reorg-cap's worth of blocks it named the null seed, whose 256 MiB cache only genesis hashes under. The cache store also had no way to empty a slot: the seed a window stopped naming stayed resident until the next epoch's pin demoted something into its place, about 62% of each epoch, in every epoch. The window now stops at the store's lowest poppable height (genesis is never popped), an alternative that would pop below that height is refused as past the reorg cap before its seed is looked up, and the cache store empties its second slot when the window names one seed. Rule 76 now names the floor's memory: a Raspberry Pi 4 Model B with 4 GB, with memory measurements on the 8 GB test board run under a 4 GiB cgroup limit.
