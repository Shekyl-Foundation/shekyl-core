- **Serve credit comes only from admitted bundles (SO-D12 4b; regenesis).** A block now carries a bundle section: the references to the serve-credit bundles it admits, committed by the header's last 32 bytes (`bundle_root`, which replaces the attestation root). `validate` admits the section through CEN-J29 to J37 (`rules::bundle_admission`), and a pass is recorded as a bit in the issued-draw index. The block template fills the section, a mined block carries it, and chain sync fetches each block's bundle bodies with the block (P2P 2014). Every network's genesis moved, so this ships as a regenesis.
- **Deleted with the old carrier:** the serve-credit input (`Input::ServeCredit`; input tag `0x02` is now unassigned and refused like any unknown tag, CEN-G2) with its pass records, verifier, store table and challenge helpers; the coinbase attestation field (`tx_extra` tag `0x0B`, now unknown); the identity-key pass path (`ResidentPassKey`; serving signs with the FN-DSA hybrid receipt key only, and the serve envelope is 1,356 bytes); the pass-anchor window; the frozen complete-tree set (a complete tree is a support-stream member, never in an epoch's drawable set); `file_prior_epoch`; bond `post_kind` 0 (byte 0 is an unknown kind, refused by retention); and the regtest draw door and serve-credit injector with the corpus `Inject` event and `shekyl-chain-replay --inject`.
- **The support carry is stored per block.** `archival_support_block[h]` holds the block's seats and the carry each tree is owed after it, and SI-43 holds each row to one step of the carry from the row before it. `archival_support_unissued` is deleted. The release cooldown reads `GRACE + 1` epochs.
- **Captured chains:** the E2 replay corpus is format 4 (tag `0x03` is refused) and its manifest format 5, and the five regtest chains are recaptured. The store's prune and slash-scan tests run on a new captured chain of real spends (`shekyl-harness-spender/vectors/shard-fill.bin`, 161 blocks closing three shards) instead of padded serve-credit bodies.
