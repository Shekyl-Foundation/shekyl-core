- **The development rules are two series.** Estate rules (00–99) are shared by shekyl-core, the GUI wallet and prism, held here and copied verbatim; shekyl-core's own rules are 101–199, each with the last two digits it had. A rule's frontmatter now says which series it is in and, for an estate rule, which repositories it governs. A retired or renumbered number is never used again: the list is `.cursor/rules/vacated-numbers.tsv`, and every citation in the tree was rewritten to the rule's new number, or to the record that keeps a retired rule's text.
- **Removed: `shekyl_relay_privacy::EmbargoDistribution`.** It was a deprecated second name for `DelayFamily`.
