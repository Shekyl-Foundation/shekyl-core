- **The Tor live tests that kill Tor now run on Windows and macOS too** (`tor-pin-verify`, `TOR_SUPERVISOR.md` §7).
  - **How Tor is killed.** One test helper, `shekyl-tor-control-client` `outside_kill::kill_tor_named_by`, kills a managed Tor from outside. The process must be named `tor` (`tor.exe` on Windows), and its command line must contain the test's data directory as text: `pkill -9 -f` on Unix, with the path escaped so it is not a regular expression, and `Stop-Process -Force` on Windows. Nothing killed is exit 1. Any other tool failure panics.
  - **Wallet tests.** The wallet's three respawn tests (crash and respawn, the onion republished on every incarnation, the degraded episode) were `#[cfg(unix)]` and now run on Windows. The fourth, the bootstrap-timeout restart, does not kill Tor and is required by name with them.
  - **Daemon tests.** The daemon's death-watcher and probe-respawn tests were Linux-only and now run on Windows and macOS. The death watcher expects the exit code `outside_kill::reaped_exit_code` reports: none after a signal, `-1` after `TerminateProcess`.
  - **Workflow.** The four wallet live tests and the five daemon live tests are each one list, required by name on every `tor-pin-verify` entry. A platform that cannot run a test leaves it off that entry's own list. These two sets have no such test.
