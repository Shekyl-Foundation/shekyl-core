- **Windows deadlines and ages leave S3 sleep and hibernation out.** The process clock reads the unbiased interrupt time on Windows, as it already reads `CLOCK_MONOTONIC` on Linux and `CLOCK_UPTIME_RAW` on macOS. That count does not include Modern Standby: the kernel keeps running, and a standby ends a wait at the wake the way `Instant` did (measured 2026-11-11, `TOR_SUPERVISOR.md` `TSR-M8`). The wallet's and the daemon's Tor waits (bootstrap, control replies, retry, reap, and the time an incarnation must hold before its alarm clears) count that clock, so an S3 sleep or a hibernation no longer ends them at the wake. A guard's rotation stays on the wall clock, because its expiry is a time of day.
