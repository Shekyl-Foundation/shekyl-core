- **Windows deadlines and ages leave a machine's sleep out.** The process clock reads the unbiased interrupt time on Windows, as it already reads `CLOCK_MONOTONIC` on Linux and `CLOCK_UPTIME_RAW` on macOS. The wallet's and the daemon's Tor waits (bootstrap, control replies, retry, reap, and the time an incarnation must hold before its alarm clears) count that clock, so a sleep no longer ends them at the wake. A guard's rotation stays on the wall clock, because its expiry is a time of day.
