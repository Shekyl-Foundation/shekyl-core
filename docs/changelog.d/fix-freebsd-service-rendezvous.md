- **FreeBSD runs the daemon as a service.** A FreeBSD `--service` start was refused, because the platform named no service rendezvous directory. It is now `/var/run/shekyl` (`RPC_CHANNEL.md` §7.1, ruled 2026-11-14), checked as on Linux. A new rc.d script, `contrib/packaging/freebsd/shekyld`, creates it with the data home `/var/db/shekyl` (0700) and `/var/log/shekyl`, and runs `shekyld --service` as the `shekyl` account under daemon(8). The FreeBSD release archive carries it as `rc.d/shekyld`, and the launch-recipe gate checks it as it checks the systemd units.
