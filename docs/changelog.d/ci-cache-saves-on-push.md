- **CI: build caches are saved by push runs only, and the Windows job has one** (`rust-audit-test.yml`, `multisig-feature.yml`, `schema-snapshot.yml`, `build.yml`; `docs/CI_TIMING_BASELINE.md`). A cache a pull request saves is readable by that pull request alone, and those saves (2.6 GB per Rust job run, 1.3 GB per schema-snapshot run) filled the repository's 10 GB and evicted the `dev` caches, so the Rust job compiled cold on every run. Pull requests now restore and never save; the Windows MSVC job caches `rust/target`, which every Rust step in it builds into; the schema-snapshot workflow also runs on pushes to `dev`, which save its cache, and its version-bump check, which reads a pull request's diff, runs on pull requests only.
